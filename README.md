# DNDC-GHG-Model 
# 🌱 DNDC Shiny App Template – Simulating Soil GHG Emissions

This project provides a simplified **R Shiny web application** that models key soil biogeochemical processes, inspired by the DNDC (DeNitrification-DeComposition) model. It simulates nitrogen dynamics and nitrous oxide (N₂O) emissions from agricultural soils under varying environmental and management conditions.

---

## 🚀 Features

- Interactive UI for setting:
  - Simulation duration
  - Carbon input rates
  - Soil moisture
  - Temperature
  - Nitrogen fertilizer inputs
- Dynamic plotting of N₂O emissions over time
- Built using simplified DNDC logic with first-order decomposition and nitrogen transformation pathways
