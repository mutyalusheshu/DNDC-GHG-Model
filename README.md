# DNDC-GHG-Model 
# 🌱 DNDC Shiny App – Simulating Soil GHG Emissions

This project provides a simplified **R Shiny web application** that models key soil biogeochemical processes, inspired by the DNDC (DeNitrification-DeComposition) model. It simulates nitrogen dynamics and nitrous oxide (N₂O) emissions from agricultural soils under varying environmental and management conditions.
